# Working with the site owner

## Asking questions
- When you need answers to more than two questions, never list them in chat. Make a form (a claude.ai Artifact page that saves answers with the `db` capability) with each question numbered and an answer box directly under it, and send the link. Use tick boxes or single-choice options where the answer is a choice, plus an optional notes box. Read the answers back with ArtifactData.
- One or two quick questions can go in chat.
